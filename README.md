# 🎀 Automação de Cadastro de Produtos

Projeto desenvolvido em Python utilizando PyAutoGUI e Pandas para automatizar o cadastro de produtos em um sistema web.

---

## 🌸 Sobre o projeto

Durante meus estudos em Python, desenvolvi esta automação para praticar:

- 🐍 Python
- 🤖 Automação de tarefas
- 📊 Pandas
- ⌨️ PyAutoGUI
- 📁 Leitura de arquivos CSV
- 🔄 Estruturas de repetição

A automação realiza login no sistema, lê uma base de dados e cadastra automaticamente todos os produtos disponíveis.
